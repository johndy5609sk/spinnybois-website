SpinnyWFC Error Codes

Real Nintendo WFC and server-side errors, reordered by chaos, explained by SpinnyWFC. Use the search box. Breathe.
20100 – Unable to Connect to Server
The server didn’t respond. It might be asleep, gone, or just dramatically ignoring you.
Check: DNS, server URL, or whether the service actually exists.
20110 – Service Discontinued
You’re asking Nintendo’s old WFC servers to wake up. They retired years ago.
Use an alternative service like SpinnyWFC instead of the original WFC endpoint.
31020 – Matchmaking Failed
No one joined your room. Even the imaginary players didn’t show up.
Try again, check NAT type, or convince a friend to actually connect.
31080 – Friend Code Error
The friend code system did what it does best: fail in mysterious ways.
Double‑check the code, region, and whether both sides added each other.
50000 – SAKE General Failure
The stats/leaderboard server saw your request and immediately regretted its life choices.
Generic SAKE error. Check request format, auth, and server status.
50020 – SAKE Authentication Failed
Your leaderboard login wasn’t accepted. The server said “who dis?”
Verify profile, auth token, and that the game is using the right account.
50030 – SAKE Record Not Found
You tried to fetch a record that doesn’t exist. It never lived here.
Check IDs, filters, or whether the data was ever uploaded.
50040 – SAKE Permission Denied
You asked to touch data you’re not allowed to touch. The server said “nope.”
Check ownership, permissions, and access level.
50050 – SAKE Upload Failed
Your stats or level tried to upload and tripped on the way to the server.
Check connection stability and payload size/format.
50060 – SAKE Download Failed
The server tried to send data and then changed its mind mid‑flight.
Check filters, IDs, and whether the content still exists.
50099 – SAKE Meltdown
The leaderboard system encountered something so cursed it gave up entirely.
Server‑side issue. Check logs, schemas, and recent changes.
52000 – Unable to Obtain IP Address
Your DS politely asked the router for an IP. The router pretended not to hear.
Check DHCP, Wi‑Fi password, and that the router isn’t sulking.
52001 – Cannot Connect to Access Point
Your Wi‑Fi saw your DS and said “not today.”
Move closer, re‑enter the key, or check MAC filtering.
52002 – DHCP Timeout
The router is thinking… and thinking… and then stopped thinking.
Restart router, check DHCP pool, or try manual IP settings.
52003 – Unable to Connect to Server
Your DS reached out. The server ghosted you.
Check server address, DNS, and whether the service is actually running.
52100 – DNS Error
Your DNS settings are so wrong the DS got confused and walked away.
Use known‑good DNS (like your router or a public resolver).
52101 – Cannot Connect to Nintendo WFC
Your network is allergic to online play. It broke out in timeouts.
Check firewall, NAT, and whether you’re tunneling through three VPNs.
52102 – Router Refused Connection
Your router blocked the DS like it’s guarding state secrets.
Check port blocking, parental controls, and security mode.
52103 – DNS Response Invalid
Your DNS replied with something so weird the DS questioned reality.
Check custom DNS, hosts overrides, or typos in server names.
60000 – GPCM General Failure
The presence/login server saw your request and immediately regretted it.
Check credentials, server URL, and protocol version.
60010 – GPCM Login Rejected
Your console tried to log in. GPCM said “nope, not you.”
Verify profile, password/token, and account status.
60020 – GPCM Buddy List Failure
The buddy list system tripped over its own data.
Check friend data, IDs, and server‑side buddy storage.
60030 – GPCM Keepalive Timeout
The server assumed you vanished into the void.
Connection dropped or idle too long. Check stability and timeouts.
61010 – Cannot Connect to Authentication Server
The login server is busy doing absolutely nothing.
Check NAS URL, DNS, and whether the auth service is running.
61020 – Profile Mismatch
The server checked your profile and said “who are you again?”
Profile data doesn’t match. Recreate or resync the profile.
61030 – Invalid Credentials
Your login details were so wrong the server winced.
Check keys, tokens, and any patched credentials.
61040 – Banned or Blocked
The server remembers you. That’s the problem.
Account or console may be blocked. Check server policy.
61050 – Region or Title Not Allowed
This game or region isn’t invited to the party.
Check region locks, title IDs, and server configuration.
61070 – Server Maintenance
The server is on a coffee break and refuses to multitask.
Try again later. Or sooner. Or whenever it feels like working.
70000 – DLS1 General Failure
The download server saw your request and immediately dropped it.
Check URL, content ID, and server status.
70010 – Content Missing
You tried to download something that doesn’t exist anymore. Or ever.
Verify content IDs and that the file is actually hosted.
70020 – Hash Mismatch
The file arrived, but the checksum screamed in horror.
Corrupted download or wrong file. Re‑upload or retry.
70030 – Download Incomplete
The download stopped halfway, like it remembered something urgent.
Check connection stability and timeouts.
84020 – Connection Failed
Your console tried to handshake. The server left it hanging.
Check ports, NAT, and whether the endpoint is correct.
84030 – NAT Negotiation Failed
Your network is behind seven firewalls and at least one dragon.
UPnP, port forwarding, or a less cursed router may help.
86010 – NAT Negotiation Failed
The peers tried to meet in the middle. The middle exploded.
Strict NAT on one or both sides. Check router settings.
86020 – Peer Unreachable
The other player lives behind a network fortress.
One side may be fully blocked. Try a different network.
86420 – Peer-to-Peer Connection Failed
The other player’s connection spontaneously combusted. Not your fault. Probably.
Common in Wii/DS P2P. Try again or pick a different host.
98020 – HTTP Request Failed
Your HTTP request left the console and never came back.
Check URL, SSL (if any), and server availability.
98030 – Malformed Request
The server looked at your request and said “what is this?”
Headers, body format, or query parameters may be wrong.
98040 – Invalid Server Response
The server replied with something so cursed the client refused to parse it.
Check response format, encoding, and status codes.
98050 – Rate Limited
You asked the server for too much, too fast. It’s hiding now.
Slow down requests or add backoff logic.
98099 – GameStats Meltdown
The stats/HTTP backend encountered something unspeakable and bailed.
Server‑side issue. Check logs and recent deployments.
998001 – Internal Server Oops
Something broke on our end. We’re pretending it didn’t happen.
Check server logs, exceptions, and anything you “definitely didn’t touch.”
998002 – Unexpected Response
The server received something so strange it questioned reality.
Client and server may disagree on protocol or payload.
998003 – Database Unavailable
The database is currently on vacation and did not leave a forwarding address.
Check DB connection, migrations, and whether it’s actually running.
